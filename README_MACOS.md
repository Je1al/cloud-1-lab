# Запуск лабораторной на macOS

## Один раз: установить .NET 8 SDK

```zsh
brew install dotnet@8
echo 'export DOTNET_ROOT="/opt/homebrew/opt/dotnet@8/libexec"' >> ~/.zshrc
echo 'export PATH="/opt/homebrew/opt/dotnet@8/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
dotnet --version
```

Последняя команда должна вывести версию `8.x`.

## Запуск

В Terminal перейдите в корень распакованного проекта и выполните:

```zsh
zsh run-lab.zsh
```

Скрипт сам проверит .NET 8, при необходимости установит его через Homebrew и
запустит симулятор с воспроизводимым `seed = 42`. Для ручного запуска:

```zsh
dotnet run --project RRC.Runner -- --seed 42 --trace 10
```

`--trace 10` выводит подробную трассировку первых десяти запросов.

В `RRC.Runner/Program.cs` уже подключён `AdaptiveRequestPolicy`.
Для сдачи по методичке передаётся только файл
`RRC.Student/AdaptiveRequestPolicy.cs`.

## Почему политика не делает повторных запросов

В этой симуляции тайм-аут не отменяет уже начатую серверную работу. Ретрай в
такой момент создаёт дубликат и увеличивает нагрузку. Политика выбирает
консервативный тайм-аут в 2 секунды, не добавляет дублирующих попыток и
увеличивает лимит для следующих запросов, если всё же встретила тайм-аут.
